## Installation

### Frontend
```
cd frontend
npm install
```

### Backend
```
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## How to Run

### Frontend
```
cd frontend
npm run dev
```

### Backend
```
cd backend
uvicorn src.main:app --reload
```
